# VICARE — QR links

Trang liên kết VICARE dạng tĩnh, thiết kế responsive cho điện thoại và máy tính.

## Chạy thử

Mở `index.html` trong trình duyệt.

## Deploy lên Vercel

Import repository này vào Vercel và giữ framework preset là **Other**. Đây là trang tĩnh nên không cần lệnh build hay thư mục output riêng; Vercel sẽ phục vụ `index.html` ở thư mục gốc.
